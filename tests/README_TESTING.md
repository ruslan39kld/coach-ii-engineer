# 🚀 Как запустить бота для тестирования

## 📋 Доступные режимы

### ✅ 1. ОФЛАЙН тестирование FAQ (РЕКОМЕНДУЕТСЯ)
**Не требует интернета, работает всегда**

```bash
TEST_FAQ.bat
```

Или:
```bash
python test_faq_simple.py
```

**Что делает:**
- Поиск по базе из 1147 вопросов
- Показывает вопросы и ответы
- Работает полностью офлайн

**Пример использования:**
```
🔍 Поиск: регистрация
✅ Найдено: 3 результатов

1. Как мне зарегистрироваться в системе?
   📄 Источник: Инструкции заказчика.xlsx
   💬 Ответ: Для регистрации необходимо...
```

---

### ✅ 2. Локальное тестирование с AI
**Требует интернет для Claude API**

```bash
TEST_LOCAL.bat
```

Или:
```bash
python test_bot_local.py
```

**Что делает:**
- Использует Claude AI для ответов
- Ищет в FAQ базе
- Работает без Telegram

**Пример:**
```
❓ Ваш вопрос: Как создать план-график?
⏳ Обработка...

💬 ОТВЕТ БОТА:
## Создание плана-графика
Для создания плана-графика выполните...
```

---

### ✅ 3. Запуск в Telegram
**Требует VPN или прокси**

```bash
START_BOT.bat
```

**Перед запуском:**
1. Включите VPN
2. Или настройте прокси в `src/bot.py`

---

## 🎯 ГЛАВНОЕ МЕНЮ

Самый удобный способ - использовать главное меню:

```bash
MENU.bat
```

**Меню включает:**
1. Запуск в Telegram
2. Локальное тестирование с AI
3. Тестирование FAQ (офлайн)
4. Загрузка FAQ из Excel
5. Статистика базы данных

---

## 🔧 Быстрый старт

### Шаг 1: Проверьте FAQ базу
```bash
python verify_db.py
```

Должно показать:
```
Total questions in DB: 1147
```

### Шаг 2: Запустите офлайн тест
```bash
TEST_FAQ.bat
```

### Шаг 3: Попробуйте поиск
Введите: `регистрация` или `план-график`

---

## ❌ Если возникли проблемы

### FAQ база пуста
```bash
python load_faq_win.py
```

### Ошибка подключения к Telegram
- Используйте `TEST_FAQ.bat` или `TEST_LOCAL.bat`
- Или включите VPN

### Ошибка Claude API
- Проверьте `.env` файл
- Убедитесь что `CLAUDE_API_KEY` установлен
- Используйте `TEST_FAQ.bat` (не требует Claude)

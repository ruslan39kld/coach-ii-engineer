# 🔧 Решение проблем с подключением

## ❌ Ошибка: `httpx.ConnectError` / `NetworkError`

### Причина:
Telegram API заблокирован или недоступен в вашей сети.

### ✅ Решения:

#### 1. Использовать VPN
Самый простой способ - включить VPN на компьютере перед запуском бота.

#### 2. Настроить прокси в боте

Откройте файл `src/bot.py` и найдите строку:
```python
proxy_url = None
```

Замените на:
```python
proxy_url = "socks5://127.0.0.1:1080"  # Ваш SOCKS5 прокси
# или
proxy_url = "http://proxy.example.com:8080"  # HTTP прокси
```

#### 3. Увеличить таймауты (если медленный интернет)

В файле `src/bot.py` найдите:
```python
connect_timeout=60.0,
read_timeout=60.0,
```

Увеличьте до:
```python
connect_timeout=120.0,
read_timeout=120.0,
```

#### 4. Проверить интернет соединение
```bash
# Windows
ping api.telegram.org

# Если не пингуется - нужен VPN/прокси
```

## 🔄 Автоматическое переподключение

Бот автоматически пытается переподключиться при потере связи.
Если ошибка повторяется:

1. **Проверьте VPN** - включен ли он
2. **Перезапустите бот** - `START_BOT.bat`
3. **Проверьте логи** - `logs/bot.log`

## 📝 Настройка SOCKS5 прокси (для продвинутых)

### Windows:
1. Установите прокси-клиент (например, Shadowsocks, V2Ray)
2. Запустите его на порту 1080
3. В `src/bot.py` установите:
   ```python
   proxy_url = "socks5://127.0.0.1:1080"
   ```

### Проверка прокси:
```bash
curl --socks5 127.0.0.1:1080 https://api.telegram.org/bot<YOUR_TOKEN>/getMe
```

## ⚡ Быстрое решение

**Самый простой способ:**
1. Включите VPN на компьютере
2. Перезапустите бота: `START_BOT.bat`
3. Бот должен подключиться через VPN

---

## 🆘 Если ничего не помогает

Свяжитесь с администратором сети или используйте другое интернет-подключение (например, мобильный интернет через точку доступа).

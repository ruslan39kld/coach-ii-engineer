# Тесты бота ЕАСУЗ

## Структура тестов

### Основные тесты

1. **test_db_and_qa_comprehensive.py** - Комплексный тест базы данных и системы вопрос-ответ
   - Проверка определения и подключения к БД
   - Проверка структуры таблиц
   - Проверка содержимого FAQ
   - Тестирование поиска
   - Проверка качества распознавания Q&A
   - Общая статистика

2. **test_database_verification.py** - Детальная проверка базы данных
   - Структура БД
   - Содержимое таблиц
   - Примеры данных

3. **test_bot_integration.py** - Тест интеграции с FAQ
   - Проверка работы FAQ системы
   - Интеграция с ботом

4. **test_complete_bot_system.py** - Полный тест системы
   - Комплексная проверка всех компонентов

### Вспомогательные тесты

- **verify_db.py** - Быстрая проверка БД
- **simple_test.py** - Простой тест базы данных и FAQ
- **test_faq_search.py** - Тест поиска в FAQ
- **test_faq_simple.py** - Упрощенный тест FAQ
- **test_bot_local.py** - Локальное тестирование бота
- **test_connection.py** - Тест подключений

## Запуск тестов

### Быстрый тест (рекомендуется)
```batch
QUICK_TEST.bat
```

Запускает 4 основных теста:
1. Проверка базы данных
2. Комплексный тест БД и Q&A
3. Тест интеграции с FAQ
4. Полный тест системы

### Отдельные тесты

#### Комплексный тест БД и Q&A
```batch
python tests\test_db_and_qa_comprehensive.py
```

#### Проверка базы данных
```batch
python tests\test_database_verification.py
```

#### Простой тест
```batch
python tests\simple_test.py
```

#### Быстрая проверка БД
```batch
python tests\verify_db.py
```

## Результаты тестирования

Результаты сохраняются в:
- `tests/TEST_DB_QA_RESULTS.md` - Результаты комплексного теста БД и Q&A
- `tests/TEST_RESULTS.md` - Общие результаты тестирования

## Что проверяют тесты

### База данных
- ✅ Существование файла БД
- ✅ Размер базы данных
- ✅ Подключение к БД
- ✅ Наличие всех таблиц (faq, documents, queries, users)
- ✅ Структура таблиц
- ✅ Количество записей

### FAQ система
- ✅ Наличие вопросов и ответов
- ✅ Качество данных (нет пустых полей)
- ✅ Источники FAQ
- ✅ Уникальность вопросов
- ✅ Адекватная длина вопросов и ответов
- ✅ Соотношение длины ответов к вопросам

### Поиск
- ✅ Функциональность поиска
- ✅ Качество результатов поиска
- ✅ Релевантность ответов
- ✅ Тестовые запросы по разным темам:
  - Регистрация в ЕАСУЗ
  - План-график закупок
  - Контракты с единственным поставщиком
  - СМСП закупки
  - Экономия по контракту

## Критерии успешности

### Отлично ✅
- Все тесты пройдены
- FAQ база содержит > 100 записей
- Качество поиска > 80%
- Все вопросы и ответы заполнены

### Хорошо ⚠️
- Большинство тестов пройдено
- FAQ база содержит > 50 записей
- Качество поиска > 60%
- Минимум пустых полей

### Требуется внимание ❌
- Провалены критические тесты
- FAQ база < 50 записей
- Качество поиска < 40%
- Много пустых полей

## Устранение проблем

### База данных не найдена
```batch
# Загрузить FAQ из Excel файлов
python scripts\load_faq_win.py
```

### Пустая FAQ база
1. Проверьте наличие Excel файлов в папке `data/`
2. Запустите загрузку FAQ: `python scripts\load_faq_win.py`
3. Проверьте формат Excel файлов (должны быть колонки "Вопрос" и "Ответ")

### Низкое качество поиска
1. Проверьте качество вопросов в FAQ
2. Убедитесь, что вопросы содержат ключевые слова
3. Проверьте, что ответы релевантны вопросам

## Автоматизация

Для регулярного тестирования можно настроить автоматический запуск:
1. Добавить в планировщик задач Windows
2. Запускать после обновления FAQ базы
3. Запускать перед деплоем новой версии

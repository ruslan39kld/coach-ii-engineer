  БЫСТРОЕ РЕШЕНИЕ ОШИБКИ ПОДКЛЮЧЕНИЯ К TELEGRAM
═══════════════════════════════════════════════════════════

ОШИБКА: httpx.ConnectError / NetworkError

ПРИЧИНА: Telegram API заблокирован в вашей сети

═══════════════════════════════════════════════════════════
  РЕШЕНИЕ 1: ИСПОЛЬЗОВАТЬ VPN (РЕКОМЕНДУЕТСЯ)
═══════════════════════════════════════════════════════════

1. Включите VPN на компьютере
2. Запустите: START_BOT.bat
3. Бот подключится через VPN

═══════════════════════════════════════════════════════════
  РЕШЕНИЕ 2: НАСТРОИТЬ ПРОКСИ В БОТЕ
═══════════════════════════════════════════════════════════

1. Откройте файл: src\bot.py
2. Найдите строку (около строки 107):
   proxy_url = None

3. Замените на ваш прокси:
   proxy_url = "socks5://127.0.0.1:1080"
   
   ИЛИ для HTTP прокси:
   proxy_url = "http://proxy.example.com:8080"

4. Сохраните файл
5. Запустите: START_BOT.bat

═══════════════════════════════════════════════════════════
  РЕШЕНИЕ 3: ПРОВЕРИТЬ ИНТЕРНЕТ
═══════════════════════════════════════════════════════════

Откройте командную строку и выполните:
ping api.telegram.org

Если не пингуется - используйте VPN или прокси.

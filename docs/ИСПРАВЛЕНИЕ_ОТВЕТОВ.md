## 🚨 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ:

### 1. Бот не отвечает на вопросы
**Проверьте:**
```powershell
# Проверьте, что бот запущен
python check_bot_status.py

# Проверьте логи
powershell -Command "Get-Content logs\bot.log -Tail 20"
```

**Решение:**
```powershell
# Перезапустите бота
powershell -Command "Get-Process python | Stop-Process -Force"
python run_bot.py
```

### 2. Ошибка "CLAUDE_API_KEY не установлен"
**Проверьте `.env` файл:**
```
CLAUDE_API_KEY=ваш_ключ_здесь
```

### 3. Ошибка "База знаний пуста"
**Загрузите базу знаний:**
```powershell
# Через админ-команду (если вы админ)
# В Telegram отправьте боту: /reload
```

### 4. Долгое ожидание ответа
**Это нормально!** Claude AI обрабатывает запрос и ищет в базе знаний.
Обычное время ответа: 2-10 секунд.

### 5. Ошибка "Произошла ошибка при обработке запроса"
**Проверьте логи:**
```powershell
powershell -Command "Get-Content logs\bot.log -Tail 50"
```

Возможные причины:
- Нет доступа к Claude API
- База знаний не загружена
- Проблемы с сетью

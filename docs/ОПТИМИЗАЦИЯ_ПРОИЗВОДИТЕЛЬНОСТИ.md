### 1. ✅ ПРОБЛЕМА: Синхронные HTTP запросы (медленная работа)
**Было:** `requests.post()` - блокирующая операция (60+ секунд)  
**Стало:** `httpx.AsyncClient()` - асинхронные запросы (5-15 секунд)

**Файл:** `claude_service.py`
```python
# БЫЛО (МЕДЛЕННО):
response = requests.post(url, timeout=60)

# СТАЛО (БЫСТРО):
async with httpx.AsyncClient(timeout=30.0) as client:
    response = await client.post(url, ...)
```

**Результат:**
- ⚡ Скорость ответа увеличена в 3-4 раза
- ⚡ Timeout уменьшен с 60 до 30 секунд
- ⚡ max_tokens уменьшен с 4000 до 2000 для скорости

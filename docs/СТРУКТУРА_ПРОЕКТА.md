# Структура проекта EASUZ Bot

## 📁 Организация файлов

### `/src` - Исходный код бота
Основной код приложения:
- `bot.py` - Главный файл бота
- `handlers.py` - Обработчики команд и сообщений
- `database.py` - Работа с базой данных
- `claude_service.py` - Интеграция с Claude AI
- `prompts.py` - Промпты для AI
- `config.py` - Конфигурация
- `keyboards.py` - Клавиатуры Telegram
- `yadisk_loader.py` - Загрузка с Яндекс.Диска

### `/tests` - Тесты
Все тестовые скрипты:

#### Основные тесты
- `test_db_and_qa_comprehensive.py` ⭐ - **Комплексный тест БД и Q&A**
- `test_database_verification.py` - Детальная проверка БД
- `test_bot_integration.py` - Тест интеграции с FAQ
- `test_complete_bot_system.py` - Полный тест системы

#### Вспомогательные тесты
- `verify_db.py` - Быстрая проверка БД
- `simple_test.py` - Простой тест
- `test_faq_search.py` - Тест поиска
- `test_faq_simple.py` - Упрощенный тест FAQ
- `test_bot_local.py` - Локальное тестирование
- `test_connection.py` - Тест подключений
- `test_claude_api.py` - Тест Claude API

#### Batch файлы для тестов
- `TEST_FAQ.bat` - Тест FAQ
- `TEST_LOCAL.bat` - Локальный тест

#### Результаты
- `TEST_RESULTS.md` - Общие результаты
- `TEST_DB_QA_RESULTS.md` - Результаты теста БД и Q&A
- `README_TESTS.md` - Документация по тестам

### `/scripts` - Скрипты
Утилиты и вспомогательные скрипты:
- `load_faq_win.py` - Загрузка FAQ из Excel
- `run_bot.py` - Запуск бота
- `start_bot_verbose.py` - Запуск с подробным выводом
- `update_env.py` - Обновление переменных окружения
- `update_yadisk_url.py` - Обновление URL Яндекс.Диска

### `/data` - Данные
- `bot.db` - База данных SQLite
- `*.xlsx` - Excel файлы с FAQ

### `/docs` - Документация
Документация проекта

### `/logs` - Логи
Файлы логов работы бота

### Корневая папка
Файлы запуска и конфигурации:

#### Запуск бота
- `run.py` - Главный файл запуска
- `START_BOT.bat` - Запуск бота
- `START_BOT_WITH_PROXY.bat` - Запуск с прокси
- `MENU.bat` - Главное меню

#### Тестирование
- `QUICK_TEST.bat` ⭐ - **Быстрый тест (рекомендуется)**

#### Конфигурация
- `.env` - Переменные окружения
- `requirements.txt` - Зависимости Python
- `amvera.yml` - Конфигурация деплоя

#### Документация
- `README_TESTING.md` - Документация по тестированию
- `TROUBLESHOOTING.md` - Решение проблем
- `FAQ_LOADING_SUMMARY.md` - Информация о загрузке FAQ
- `СТРУКТУРА_ПРОЕКТА.md` - Этот файл
- `ИТОГИ_ТЕСТИРОВАНИЯ.txt` - Итоги тестирования
- `РЕЗУЛЬТАТЫ_ТЕСТИРОВАНИЯ.md` - Результаты тестирования


### 2. Тестирование
```batch
QUICK_TEST.bat
```

### 3. Загрузка FAQ


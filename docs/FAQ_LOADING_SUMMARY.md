## 📝 СТРУКТУРА ДАННЫХ

### Таблица `faq`:
- `id` - уникальный идентификатор
- `question` - текст вопроса
- `answer` - текст ответа
- `source_file` - имя исходного Excel файла

### Формат Excel файлов:
- Строка 0: пустая или заголовок документа
- Строка 1: заголовки колонок (№, Вопрос, Ответ, ...)
- Строка 2+: данные (вопросы и ответы)
